# 自動ズーム対応の無料画面録画ソフト

OpenScreen は、Windows・macOS・Linux 向けの無料の MIT ライセンスの自動ズーム対応画面録画ソフトです。テイクのあと、**自動強化 → 自動ズーム**が、OpenScreen が記録したカーソルの動きを読み取り、ポインターが止まった場所にズームを追加します。通信も AI モデルも使いません。Screen Studio、Cap、Camtasia も自動ズームに対応していますが、OpenScreen は 3 つのシステムすべてで、無料でそれを行います。

このページは OpenScreen プロジェクトが公開しています。Screen Studio、Cap、Camtasia に関する情報は screen.studio、cap.so、techsmith.com によるもので、2026 年 9 月に確認しました。情報源は末尾に一覧しています。

## 概要 {#at-a-glance}

| | |
| --- | --- |
| 場所 | エディターのタイムラインツールバーにある自動強化 → 自動ズーム |
| 読み取る対象 | OpenScreen が録画と一緒に保存するカーソルの動き |
| ズームの配置場所 | ポインターが約 0.5 秒から 2.6 秒ほぼ静止していた場所 |
| 自動ズーム 1 件あたり | 1.8 倍、フォーカスはカーソルに追従。エディターで追加した場合は 2 秒間 |
| AI・通信・API キー | なし |
| 手動ズームの段階 | 1.25 倍、1.5 倍、1.8 倍、2.2 倍、3.5 倍、5 倍 |
| フォーカス | 自分で配置する点、または記録されたカーソル |
| 3D チルト | なし、Iso、左、右 |
| コマンドライン | `export` コマンドの `--auto-zoom` フラグ |
| 対応プラットフォーム | Windows 10（1903 以降）と 11、x64。macOS 13 以降、Apple Silicon と Intel。Linux、x64 |
| 価格 | 商用利用を含めて無料。MIT ライセンス |

## 自動ズームの仕組み {#how-automatic-zooms-work}

既定の編集可能なカーソルモードでは、OpenScreen はポインターをピクセルとは別に記録します。システムのカーソルは映像から除外し、その動きを隣接する `.cursor.json` ファイルに保存します。自動ズームは、このファイルから作られます。

1. **静止部分を見つける。** OpenScreen は、記録した座標の中から、ポインターが約 0.5 秒から 2.6 秒ほぼ静止している区間を探します。それぞれの静止が候補になり、ポインターが留まった位置を狙います。
2. **順位付けして間隔を空ける。** 長い静止ほど優先されます。すでに採用した候補から 1.8 秒未満しか離れていない候補は除外され、タイムライン上にすでにあるズームと重なる候補も除外されます。
3. **ズームを追加する。** エディターでは、採用された各静止が、その静止を中心に 1.8 倍で 2 秒間ズームとして配置され、フォーカスはカーソルに追従するよう設定されます。

この処理は、記録された座標に対する決定的なルールであり、AI 機能ではありません。通信を行わず、モデルも読み込まないため、Windows・macOS・Linux のいずれでも同じように動作します。

実際に使ううえで重要な点がいくつかあります。

- **自分で配置したズームはそのまま残ります。** 手動で配置したズームは保持され、新しいズームがそれらと重なることはありません。
- **クリップごとに独自のズームが付きます。** マルチクリップのタイムラインでは、たとえ 2 つのクリップが同じテイクから来ていても、それぞれのクリップが録画の対応する区間に個別に対応付けられます。
- **1 回の取り消しでまとめて削除できます。** この処理全体が 1 つの編集として扱われます。
- **結果は通常のズームです。** クリックして深さ・チルト・フォーカスを変更したり、端をドラッグして開始・終了位置を動かしたり、削除したりできます。
- **実行するのは指示したときだけです。** バージョン 1.11.0 では、エディターで自動ズームを選ぶか、コマンドラインで `--auto-zoom` を渡すまで、テイクの後に何も追加されません。
- **対象がなければ知らせます。** エディターは、自動ズームの瞬間が見つからなかったことを報告します。
- **クリックのデータは不要です。** クリックなしで記録されたテイク（例えばユーザーが `input` グループに入っていない Linux でのテイク）でも、自動ズームは適用されます。
- **長い静止はあなたが自分でフレーミングします。** スライドについて話しているときなど、ポインターが 2.6 秒を超えて留まった場合は、そのまま残されます。`Z` で手動でズームを追加してください。

同じメニューには 2 つ目の項目として、「AIを使用」と表示される**スマートカット**があります。これは別の機能で、任意のチャットエージェントに空白時間のカットを依頼します。録画の文字起こしを待ってから動作し、自分の API キーで AI プロバイダーを接続した場合にのみ機能します。詳しくは [AI 編集](/docs/ai-editing/)を参照してください。

## 手動ズームとカーソル追従フォーカス {#manual-zooms-and-cursor-following-focus}

自動ズームは出発点です。同じズーム範囲を手動で配置・調整することもできます。

- **`Z` でズームを追加。** 再生ヘッドの位置に 1.8 倍で配置され、フォーカスはフレームの中央になります。端をドラッグして開始・終了位置を設定します。
- **6 段階の深さ。** 1.25 倍、1.5 倍、1.8 倍、2.2 倍、3.5 倍、5 倍。
- **2 つのフォーカスモード。** 手動は、プレビュー上でフォーカスマーカーをドラッグするか中央にリセットして 1 点を保持します。自動は、記録されたカーソルに追従します。
- **すべてのズームに共通の 1 つの切り替え。** ツールバーのオートフォーカスの十字線アイコンをオンにすると、すべてのズームがカーソルに追従します。オフにすると、各ズームは個別の設定に戻ります。
- **3D チルト。** 各ズームは平坦のままにするか、Iso、左、右のいずれかに傾けられます。
- **ズーム中のウェブカメラ。** ピクチャーインピクチャーのレイアウトでは、**ズーム時に縮小**をオンにすると、画面がズームしている間カメラが小さくなります。既定でオンです。

手動フォーカスの手動ズームはカーソルのデータを必要としないため、ほかのツールからインポートした動画でも使えます。ズームのインスペクターについては、[ズーム範囲](/docs/editing-timeline/#zoom-regions)を参照してください。

## テイク後のカーソル {#the-cursor-after-the-take}

同じ記録された動きが、エクスポート時のカーソルの動きも決めます。**カーソル**パネルでは、表示・非表示の切り替え、カーソルテーマの選択、サイズ・スムージング・モーションブラー・クリックバウンスの設定ができます。カーソルのパスはプレビューとエクスポートで同じようにスムージングされるため、プレビューは出力ファイルと一致します。

クリックバウンスには記録されたクリックが必要です。macOS ではアクセシビリティの権限が必要で、Linux ではユーザーが `input` グループに入っている必要があります。各プラットフォームが取得する内容は[録画](/docs/recording/)に一覧しています。

## コマンドラインから {#from-the-command-line}

[CLI](/docs/cli/) の `export` コマンドは `--auto-zoom` を受け付けます。レンダリング前に、録画のカーソルデータに対して同じ静止検出を実行し、プロジェクト自体のズームと重ならないズームを追加します。これらのズームはそれぞれ、1 秒または録画の 5% のどちらか長いほうの長さになります。OpenScreen のカーソルデータがない動画には、この処理の元になるデータがありません。

## 自動ズームに対応するほかのツール {#other-tools-that-zoom-automatically}

自動ズームはこのカテゴリーで一般的な機能で、OpenScreen はそれを提供する複数のツールの 1 つです。

- **Screen Studio。** その自動ズームは、録画中にクリックが発生した場所に焦点を合わせます。
- **Cap。** その Studio Mode は、Cap が記録するカーソルとクリックのデータをもとに、記録されたクリックの周辺にズームのセグメントを生成します。そのドキュメントによると、インポートした MP4 はインポート時にクリックデータを得られません。
- **Camtasia。** SmartFocus は、スクロールやクリックなどのアクションを識別し、パンとズームのアニメーションを追加します。Camtasia Recorder からの `.trec` ファイルが必要です。

OpenScreen と同じように、Cap と Camtasia も、自身のレコーダーがキャプチャしたデータを必要とします。Screen Studio と Cap はクリックをトリガーにし、Camtasia の AI はスクロールやクリックなどのアクションを選び出し、OpenScreen はポインターの動きの静止を追いかけます。これはクリックが記録されていない場合でも機能します。並べての比較は、[Screen Studio の代替](/alternatives/screen-studio/)、[OpenScreen と Cap の比較](/compare/openscreen-vs-cap/)、[Camtasia の代替](/alternatives/camtasia/)を参照してください。

## OpenScreen が適さない場合 {#when-openscreen-is-not-the-right-tool}

- **ほかのレコーダーで撮った映像に自動ズームを使いたい場合。** 自動ズームには、OpenScreen が書き出すカーソルファイルが必要です。ほかのアプリで作った動画にはそれがなく、システムカーソルのモードで録画した OpenScreen のテイクにもありません。どちらの場合も手動ズームは使えます。
- **iPhone や iPad を録画したい場合。** OpenScreen が録画するのは、Windows・macOS・Linux のコンピューター上のディスプレイまたはウィンドウで、スマートフォンやタブレットではありません。

## はじめかた {#getting-started}

1. [ダウンロードページ](/download/)から OpenScreen を入手します。Windows では Microsoft Store の利用がおすすめです。
2. [インストール](/docs/installation/)の手順に従います。macOS では、最初の録画の前に画面収録とアクセシビリティの権限を許可してください。
3. [クイックスタート](/docs/quick-start/)で最初のテイクを録画し、カーソルモードは既定の編集可能なカーソルのままにしておきます。
4. エディターで**自動強化 → 自動ズーム**を選び、[編集とタイムライン](/docs/editing-timeline/)の説明に沿ってズームを調整します。

本格的なデモを作りたいですか。[製品デモ動画ガイド](/docs/guides/product-demo-video/)では、こうしたズームに合わせたテイクのペース配分を紹介し、[字幕のページ](/features/captions/)では端末上の文字起こしを解説しています。OpenScreen は [Windows](/screen-recorder-windows/)、[macOS](/screen-recorder-mac/)、[Linux](/screen-recorder-linux/) で動作します。または [OpenScreen のホームページ](/)に戻ってください。
