# Claude で動画を編集：無料、ローカルで動作

OpenScreen は、Windows・macOS・Linux 向けの無料の MIT ライセンスの画面録画・動画編集ソフトで、MCP サーバーを内蔵しています。Claude Code に追加すれば、Claude が製品デモの編集をまるごと行います。テイクを録画し、無駄な時間をカットし、クリックにズームし、非公開の情報を隠し、字幕をオンにし、どの編集ソフトにもないエフェクトを書き、動画をエクスポートします。OpenScreen はそのどれにも料金がかかりません。クレジットもアカウントも透かしもありません。編集はあなたのコンピューター上で動き、Claude はすでに使っている Claude のプランで動きます。

このページは OpenScreen プロジェクトが公開しており、バージョン 2.1 について説明しています。

## 概要 {#at-a-glance}

| | |
| --- | --- |
| Claude にできること | 録画、カット、速度アップ、ズーム、トリミング、クリップの並べ替え、テキスト・矢印・ぼかしの追加、音楽の追加、文字起こし、字幕の作成と翻訳、カスタムエフェクトの作成、エクスポート、結果の確認 |
| 接続方法 | OpenScreen の MCP サーバー：`mcp` を付けて起動するアプリ自身の実行ファイル、またはアプリの AI設定にあるサーバー |
| クライアント | Claude Code、Claude Desktop、Codex、Cursor、そのほかの MCP クライアント |
| OpenScreen の料金 | 無料。クレジット、アカウント、透かしはなし |
| 編集が動く場所 | あなたのコンピューター上：録画、編集、Whisper による文字起こし、エクスポート |
| 取り消し | すべての編集はプロジェクトに反映されます。開いているエディターでは `Ctrl/Cmd + Z` で取り消せます。閉じたプロジェクトでは、チェックポイントで 1 回の操作で元に戻せます |
| 対応プラットフォーム | Windows 10（1903 以降）と 11。macOS 13 以降。Linux、x64 |
| ライセンス | MIT。商用利用も無料 |

## 2 分で設定する {#set-it-up-in-two-minutes}

いちばん手早い方法は、次の内容を Claude Code に貼り付けることです。

```text
Install the OpenScreen demo skill with `npx skills add getopenscreen/openscreen --skill openscreen-demo -y`, then follow it to make a demo video of this feature.
```

このスキルは、OpenScreen がなければ、同意を得たうえでインストールし、その MCP サーバーを追加します。続いて Claude が、新しいセッションを開くよう求めます。エージェントが新しいツールを得られるのは、新しいセッションの中だけだからです。

代わりにサーバーを手動で追加するには、次のようにします。

```bash
claude mcp add openscreen -- "<executable>" mcp
```

`<executable>` はアプリの実行ファイルで、システムごとに [CLI の実行](/docs/cli/#running-the-cli)に一覧があります。この方法で起動したサーバーには、ポートもトークンも設定も不要です。OpenScreen を開いたままにして、各編集がエディターに反映されるのを見たい場合は、**AI設定** → **MCP サーバー**でサーバーをオンにし、そこに表示されるコマンドをコピーしてください（[詳細](/docs/ai-editing/#using-claude-code-codex-or-another-mcp-client)）。

## Claude で製品デモを編集する {#edit-a-product-demo-with-claude}

ふだんの言葉で頼みます。以下の依頼は、それぞれ Claude への 1 文です。

1. **テイクを録画する。**「新しいエクスポートダイアログを見せるので、設定ウィンドウを録画して」。Claude はウィンドウを一覧し、録画を開始して停止します。テイクはプロジェクトとして開き、クリックにはすでにズームが付いています。スクリプトで操作したテイク（たとえば Playwright）にも、カーソルとズームが同じように付きます。
2. **無駄な時間をカットする。**「最初の 4 秒をカットして、アップロードの待ち時間を速くして」。Claude はトリムまたは速度リージョンを追加し、編集はタイムラインに残るので、ドラッグして調整できます。
3. **大事なところにズームする。**「価格欄に入力するところにズームして」。ズームは保持され、近いクリックの間をパンし、画面を 3D で回転させることもできます。
4. **非公開の情報を隠す。**「上部バーのメールアドレスをぼかして」。ズームで映像が動いても、ぼかしは隠したいものに付いたままです。
5. **字幕を付ける。**「文字起こしして、字幕をオンにして、フランス語版も追加して」。Whisper はあなたのコンピューター上で動きます。字幕の翻訳は Claude 自身が行うので、ほかのサービスには見られません。
6. **どの編集ソフトにもないエフェクトを追加する。**「クリックごとに波紋を広げて」「画面を次のショットに焼き付けて」。下の説明を参照してください。
7. **エクスポートして確認する。**「X 用に 1080p でエクスポートして」。Claude は、ファイルを渡す前に、`getFrames` で自分の結果の静止画を確認します。

同じ手順を手作業で行う方法は、[製品デモ動画ガイド](/docs/guides/product-demo-video/)にあります。

## 画面全体を編集できる。タイムラインだけではありません {#the-whole-picture-is-editable-not-just-the-timeline}

Claude が使うツールはどれも通常の編集です。トリム、ズーム、字幕、タイムライン上のクリップです。それに加えて、OpenScreen は Claude に映像への最後の仕上げを任せます。どの設定にもない見た目を頼むと、Claude はそれを小さな GPU シェーダーとして書き、合成後のフレーム全体に適用します。録画、ウェブカメラ、カーソル、背景も含まれます。シェーダーはタイムライン上のブロックになり、設定用のスライダーが付きます。ほかのリージョンと同じように、移動も削除もできます。

エフェクトは、画面録画が知っていることを知っています。各クリックがどこに当たったか、ポインターがどこにあるか、ズーム、レイアウト、3D カメラのあとで録画がどこにあるかです。波紋は、ズームがクリックをどこへ動かしても、そのクリックから始まります。クリックしたボタンに雷を落とすこともできます。

OpenScreen は、プレビューしたとおりにエクスポートされる、メニューにないエフェクトを備えた初めてのエディターです。プレビューとエクスポートは、同じネイティブ GPU コンポジターで同じシェーダーを実行し、Windows・macOS・Linux で動作します。コスト階層を含む詳細は、[カスタムエフェクト](/docs/effects/)を参照してください。

## あなたのマシンに残るもの {#what-stays-on-your-machine}

- **編集。** 録画、すべての編集、文字起こし、エクスポートは、あなたのコンピューター上の OpenScreen で動きます。動画はどこにもアップロードされません。
- **Claude が見るもの。** Claude は、プロジェクト、求めたときの文字起こし、`getFrames` で要求した静止画を読み取ります。これらは、あなたのプランのもとで、Claude のセッションの一部として Anthropic に送られます。
- **あなたのアカウント。** OpenScreen があなたの Claude アカウントやキーを見ることはありません。Claude Code が OpenScreen を起動するのであって、その逆ではありません。

## OpenScreen が適さない場合 {#when-openscreen-is-not-the-right-tool}

- **AI で生成した映像が欲しい場合。** OpenScreen が編集するのは、録画またはインポートしたものです。動画、画像、音声は生成しません。
- **ブラウザーでチームと一緒に編集する場合。** OpenScreen はデスクトップアプリで、プロジェクトはあなたのコンピューター上のファイルです。

## はじめかた {#getting-started}

1. [ダウンロードページ](/download/)から OpenScreen を入手します。
2. [2 分で設定する](#set-it-up-in-two-minutes)のプロンプトを Claude Code に貼り付けます。
3. 最初の編集を頼みます。

[AI 編集](/docs/ai-editing/)では、すべてのツールと、Anthropic、OpenAI、Google などの自分の API キーで使える内蔵チャットパネルを説明しています。OpenScreen には、エージェントを使わない[自動ズーム](/features/auto-zoom/)と[ローカル字幕](/features/captions/)もあります。または [OpenScreen のホームページ](/)に戻ってください。

Claude と Claude Code は Anthropic の商標です。OpenScreen は独立したプロジェクトであり、Anthropic と提携しておらず、Anthropic から承認を受けてもいません。
