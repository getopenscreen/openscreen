# プライバシーポリシー

最終更新日：2026年10月19日

OpenScreen は、無料でオープンソースの画面録画・動画編集ソフトです。アカウントも独自のサーバーもありません。録画、プロジェクト、文字起こしはお使いのパソコンに保存され、録画をアップロードする機能はありません。このページでは、デスクトップアプリ、この Web サイト、MCP サーバー、エージェントプラグインから、お使いのマシンの外に出るものをすべて記載します。AI 機能が、あなたの選んだプロバイダーに送信するプロジェクトのデータも含みます。

## 責任者 {#who-is-responsible}

OpenScreen の保守者は Etienne Lescot で、ここに記載するデータのデータ管理者でもあります。連絡先：privacy@getopenscreen.com

## デスクトップアプリ {#the-desktop-app}

### 1 日 1 回の匿名カウント {#an-anonymous-daily-count}

アプリは多くても 1 日 1 回、インストールが 1 つアクティブだったことを、PostHog の EU サーバーに伝えます。カウントの内容は次のとおりです。

- アプリのバージョン、OS、プロセッサのアーキテクチャ
- アプリのインストール方法（インストーラー、Microsoft Store、AppImage、Flatpak など）
- アプリが直接使われたか、AI エージェントが MCP サーバー経由で使ったか
- そのインストールにとって、その週とその月で最初のカウントかどうか

それ以外は何も含みません。インストールを識別する ID はなく（カウントごとに新しいランダム ID が付きます）、名前も、ファイル名も、録画に関する情報も一切含みません。位置情報の取得はオフで、PostHog のプロジェクトは IP アドレスを破棄するよう設定されています。目的は、OpenScreen を何人が、どのシステムで使っているかを知ることで、これはプロジェクトの正当な利益にあたります。

無効にするには、トレイメニューの**匿名の利用カウントを送信**のチェックを外すか、環境変数 `DO_NOT_TRACK=1` を設定します。開発ビルドと CI の実行では一切送信されません。

### アプリが行う接続 {#connections-the-app-makes}

- **GitHub。** 自動でアップデートするビルドは、24 時間ごとと、ユーザーが求めたときに、新しいリリースを確認します。GitHub は IP アドレスを含むリクエストを受け取り、[同社のプライバシーステートメント](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)に従って扱います。
- **Hugging Face と GitHub（一度だけ）。** 最初の文字起こしで huggingface.co から Whisper 音声モデルをダウンロードし、GPU を搭載したマシンでは github.com から単語のタイミングを付けるモデルもダウンロードします。文字起こし自体はお使いのパソコン上で実行されます。
- **Google Fonts（バージョン 1.x で追加したフォントのみ）。** 以前のバージョンで追加したカスタムフォントは、起動時に引き続き読み込まれます。
- **AI プロバイダー（接続した場合のみ）。** チャット編集では、あなたのメッセージと、エージェントが読み取るプロジェクトのデータ（タイムラインや文字起こしなど）が送信されます。字幕の翻訳では、字幕のテキストが送信されます。プロバイダーを選び、ご自身の API キーを入力するまでは、何も送信されません。プロバイダー（Anthropic、OpenAI、Google、Mistral、OpenRouter、MiniMax、または自分で設定したサーバー）は、そのデータを各自の規約に従って扱います。キーはお使いのパソコン上に暗号化して保存されます。

アプリにはクラッシュレポートの機能はありません。**診断情報を保存**はディスクにファイルを書き込むだけで、何も送信しません。

## MCP サーバーとエージェントプラグイン {#the-mcp-server-and-the-agent-plugin}

OpenScreen の MCP サーバーはお使いのパソコン上で動作します。`openscreen mcp` は自身を起動したエージェントとやり取りし、アプリに組み込まれたサーバーはトークンで保護されたうえで 127.0.0.1 でのみ待ち受けます。エージェントとやり取りする内容は、お使いのマシンの中にとどまります。どちらかがマシンの外に送信するのは、上で説明した匿名の 1 日 1 回のカウントだけで、`openscreen mcp` もアプリと同じようにこれを送信します。接続したエージェント（Claude Code や Codex など）は、これらからプロジェクトのデータと静止フレームを受け取り、そのエージェントの規約に従って、それらを自身のモデルプロバイダーに渡すことがあります。

`openscreen-demo` スキルと、コーディングエージェント向けの OpenScreen プラグインは、あなたが求めたときにのみデータを送信します。

- プルリクエスト用の動画を求めた場合、`gh` を使って、エクスポートした動画を GitHub のプルリクエストに添付します。
- X への動画の投稿は、あなたが明示的に「はい」と答えた後にのみ行います。
- アプリのインストールに同意した場合、GitHub のリリースから OpenScreen のインストーラーをダウンロードします。

## この Web サイト {#this-website}

getopenscreen.com は Cloudflare によって配信されています。Cloudflare は、配信するリクエストを IP アドレスを含めて、[同社のプライバシーポリシー](https://www.cloudflare.com/privacypolicy/)に従って処理します。

このサイトは、PostHog の EU サーバーを使って訪問者数を計測しています。Cookie は使わず、ブラウザーに何も保存しません。記録するのは、閲覧したページ、クリックしたリンクとボタン、ダウンロードしたファイルです。訪問者は、PostHog がサーバー上で計算する日ごとのハッシュで数えられ、PostHog はこのハッシュを日をまたいで結び付けることができません。個人のプロファイルは作成されず、セッションも記録されません。目的は、どのページが OpenScreen を見つけてダウンロードする助けになっているかを知ることで、これはプロジェクトの正当な利益にあたります。

デモ動画は media.getopenscreen.com から配信されます。ベンチマークの記事は、GitHub が配信する etiennelescot.github.io から結果を読み込みます。

## データの保持期間 {#how-long-data-is-kept}

アプリの 1 日 1 回のカウントと、Web サイトの訪問者計測イベントは、PostHog に最長 1 年間保持されます。OpenScreen はそれ以外の個人データを保持しません。

## あなたの権利 {#your-rights}

GDPR に基づき、あなたは自分に関するデータへのアクセス、訂正、消去を求めること、その処理に異議を申し立てること、または処理を制限することができます。カウントには識別子が含まれないため、通常はカウントからあなたを特定することはできません。privacy@getopenscreen.com までご連絡ください。また、管轄のデータ保護機関に苦情を申し立てることもできます。フランスでは [CNIL](https://www.cnil.fr/) がこれにあたります。
