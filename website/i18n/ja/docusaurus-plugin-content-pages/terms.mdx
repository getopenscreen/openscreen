一部の機能は、あなたが選んで利用するサービスを使います。たとえば自分の API キーで接続する AI プロバイダーや、アップデートのための GitHub です。これらのサービスには各社の規約が適用されます。あなたのマシンから送信されるものは[プライバシーポリシー](/privacy/)に記載しています。
