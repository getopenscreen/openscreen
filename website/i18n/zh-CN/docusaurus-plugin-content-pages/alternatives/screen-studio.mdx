# 一款免费开源的 Screen Studio 替代品

OpenScreen 是一款面向 Windows、macOS 和 Linux 的免费 Screen Studio 替代软件，采用 MIT 许可证。和 Screen Studio 一样，它会在光标所在处自动缩放，在录制结束后重新设置光标样式，添加背景和本机字幕，并导出 MP4 或 GIF。与 Screen Studio 不同的是，后者仅支持 macOS，且需要付费方案才能导出，而 OpenScreen 不收费、无需账号。如果你需要以带评论的托管链接分享录制内容，或录制 iPhone、iPad，Screen Studio 仍是更好的选择。

本页由 OpenScreen 项目发布。关于 Screen Studio 的信息来自 screen.studio，核实于 2026 年 9 月。信息来源列于文末。

## 两款软件的共同点 {#what-both-apps-do}

以下功能两款软件都具备，并非任何一方独有。

- **自动缩放。** 两者都会自动放大画面重点。在 OpenScreen 中，**自动增强 → 自动缩放**会根据录制的光标移动放置缩放，无需联网、无需模型。六种深度的手动缩放也可与之并用。详见[自动缩放](/features/auto-zoom/)。
- **可事后调整的光标。** 两者都能在录制结束后调整光标大小、平滑或隐藏光标，并添加点击效果。OpenScreen 默认会将光标数据与视频分开录制，以实现这一点。
- **背景与画面构图。** 两者都能添加背景、内边距和阴影，并输出横向或竖向视频。OpenScreen 提供壁纸、纯色、渐变或你自己的图片，以及包括 16:9、9:16 和 1:1 在内的多种画面比例。
- **同一段录制中的摄像头、麦克风和系统音频。**
- **时间轴上的修剪、剪切、变速和运动模糊。**
- **配音与音乐。** 两者都能添加配音和背景音乐。Screen Studio 自带音乐库；OpenScreen 在时间轴上录制配音，也可以导入你自己的音频文件。
- **在本机上转录。** 两者都在本机运行 Whisper，在视频上显示字幕，并允许你修正转录文本。详见[字幕](/features/captions/)。
- **隐藏敏感内容。** Screen Studio 用遮罩模糊敏感数据；OpenScreen 提供高斯或马赛克模糊区域。
- **录制时的笔记。** 两者都有演讲者笔记功能。在 Windows 和 macOS 上，OpenScreen 的笔记窗口还带有提词器模式。
- **本地处理。** Screen Studio 表示绝不会将录制内容的数据发送到其服务器。OpenScreen 没有账号体系，没有自己的服务器，也没有分析统计。[常见问题](/docs/faq/#does-openscreen-work-offline)列出了它仍会联网的少数情形。

## OpenScreen 的不同之处 {#where-openscreen-differs}

### 价格、许可证与平台 {#price-license-and-platforms}

- **完全免费，功能不设限。** 没有付费方案，没有账号，没有锁定的导出功能，允许商业用途。
- **MIT 许可的源代码。** 代码托管在 [GitHub](https://github.com/getopenscreen/openscreen)。Screen Studio 是闭源软件。
- **支持 Windows 和 Linux，不止 macOS。** Screen Studio 的常见问题中表示近期没有推出 Windows 版本的计划。OpenScreen 提供 Windows 安装程序及 Microsoft Store 上架版本，为 Apple Silicon 和 Intel Mac 提供 `.dmg` 文件，为 Linux 提供 AppImage、`.deb`、`.rpm` 和 `.pacman` 包，还有 Nix flake。参见 [Windows](/screen-recorder-windows/)、[macOS](/screen-recorder-mac/) 和 [Linux](/screen-recorder-linux/) 页面。

### 编辑 {#editing}

- **一个项目中容纳多个片段。** 导入录制内容或已有视频（MP4、MOV、MKV 等），重新排序，并为每个片段设置入点、出点和裁剪范围。Screen Studio 可以从一段已有视频开始项目，其路线图将合并多段录制到一个项目中列为计划功能。参见[媒体库](/docs/media-library/)。
- **标注。** 六种动画效果的文字、八个方向的箭头、图片，以及模糊区域。Screen Studio 的路线图将“标注”（描述为点击的视觉或文字说明）列为暂停状态。参见[编辑与时间轴](/docs/editing-timeline/)。
- **摄像头背景。** 在正式版中即可去除、模糊或替换摄像头背景，无需绿幕。Screen Studio 将摄像头背景移除列为测试版功能。

### 导出与自动化 {#export-and-automation}

- **可选编码格式。** MP4 导出支持 H.264 或 H.265。Screen Studio 的导出指南没有提及编码格式设置。参见[导出](/docs/export/)。
- **命令行界面。** 脚本、CI 和编程代理都可以通过[命令行](/docs/cli/)驱动 OpenScreen。Screen Studio 的指南中没有命令行相关条目。
- **可选的聊天式编辑，使用你自己的密钥。** 连接 Claude、OpenAI、Gemini、Mistral、OpenRouter、MiniMax 或任意 OpenAI 兼容端点，用日常语言描述剪切、缩放、变速或标注。每次修改都是一次可撤销的普通编辑。在你连接提供方之前，此功能处于关闭状态；同一个提供方也用于将字幕翻译成 15 种语言。参见 [AI 编辑](/docs/ai-editing/)。

## 何时 Screen Studio 是更好的选择 {#when-screen-studio-is-the-better-choice}

- **以链接分享。** Screen Studio 会为最长 30 分钟的录制生成托管链接，观众可以在指定时间点留下评论。OpenScreen 给你的是一个文件，想在哪里分享就上传到哪里。
- **录制 iPhone 或 iPad。** Screen Studio 通过 USB 录制这些设备并添加设备边框。OpenScreen 录制的是 Windows、macOS 或 Linux 屏幕。
- **需要转录文本文件。** Screen Studio 可以导出转录文本；OpenScreen 是把字幕烧录进视频中。

## 开始使用 {#getting-started}

1. 从[下载页面](/download/)下载 OpenScreen。在 Windows 上，推荐通过 Microsoft Store 安装。
2. 按照[安装说明](/docs/installation/)操作。在 macOS 上，首次录制前请先授予屏幕录制和辅助功能权限。
3. 参照[快速上手](/docs/quick-start/)完成第一次录制，然后对它运行**自动增强 → 自动缩放**。
