# 使用条款

最后更新：2026 年 11 月 3 日。

OpenScreen 是一款免费、开源的屏幕录制和视频编辑软件。本条款适用于桌面应用、MCP 服务器、智能体插件以及本网站 getopenscreen.com。

## 谁提供 OpenScreen {#who-provides-openscreen}

OpenScreen 由法国的 Etienne Lescot 与贡献者共同维护。联系方式：privacy@getopenscreen.com，或在 GitHub 上提交 issue。源代码位于 [github.com/getopenscreen/openscreen](https://github.com/getopenscreen/openscreen)。

## 许可证 {#the-license}

本软件以 [MIT 许可证](https://github.com/getopenscreen/openscreen/blob/main/LICENSE)发布。你可以免费将其用于任何目的，包括商业用途，并可依该许可证复制、修改和再分发。没有账户，没有付费版本，也没有水印。

## 不提供担保 {#no-warranty}

如 MIT 许可证所述，本软件按"原样"提供，不附带任何形式的担保。请为重要的录制和项目保留副本。在法律允许的范围内，维护者不对因使用本软件造成的任何损失承担责任。

## 你的内容 {#your-content}

你的录制、项目和导出文件归你所有。它们保存在你的电脑上，OpenScreen 不对其主张任何权利。你需对自己录制和发布的内容负责，并确保有权录制其中的人物、屏幕和声音。

## 第三方服务 {#third-party-services}

部分功能依赖你自行选择使用的服务，例如用你自己的 API 密钥连接的 AI 服务商，或用于更新的 GitHub。这些服务适用其各自的条款。哪些数据会离开你的电脑，详见[隐私政策](/privacy/)。

## 官方下载渠道 {#official-downloads}

请只从本网站、GitHub Releases、Microsoft Store 或文档中列出的包管理器下载 OpenScreen。来自其他渠道的版本并非我们发布。

当 OpenScreen 的提供方式发生变化时，本条款会随之更新。顶部日期为最后修改日期，[页面历史](https://github.com/getopenscreen/openscreen/commits/main/website/src/pages/terms.mdx)记录了每一次修改。本条款受法国法律管辖。
