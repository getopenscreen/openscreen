# 免費、開源的 Screen Studio 替代方案

OpenScreen 是免費、MIT 授權，支援 Windows、macOS 與 Linux 的 Screen Studio 替代方案。和 Screen Studio 一樣，它會在游標所到之處放大畫面、在錄完後重新設計游標樣式、加上背景與裝置端字幕，並匯出 MP4 或 GIF。與只能在 macOS 上執行、需要付費方案才能匯出的 Screen Studio 不同，OpenScreen 完全免費，也不需要帳號。如果你需要以帶留言功能的託管連結分享錄影，或需要錄製 iPhone 或 iPad，Screen Studio 仍然是較好的選擇。

本頁由 OpenScreen 專案發布。Screen Studio 的資訊來自 screen.studio，於 2026 年 9 月確認。資料來源列於文末。

## 兩者共通的功能 {#what-both-apps-do}

以下功能兩款應用程式都有，並非任一方獨有。

- **自動縮放。** 兩者都會在有動作的地方放大。在 OpenScreen 中，**自動加強 → 自動縮放**會根據錄下的游標移動放置縮放，不需要連線，也不需要模型。另外還有六種深度的手動縮放可搭配使用。詳見[自動縮放](/features/auto-zoom/)。
- **可在事後更改的游標。** 兩者都能在錄完後調整游標大小、使其平滑或隱藏，並加上點擊效果。OpenScreen 預設會把指標與畫面分開錄製，以便做到這一點。
- **背景與構圖。** 兩者都能加上背景、內邊距與陰影，並輸出橫向或直向影片。OpenScreen 提供桌布、純色、漸層或自訂圖片，以及包含 16:9、9:16 與 1:1 在內的多種長寬比。
- **同一次錄影中的攝影機、麥克風與系統音訊。**
- **時間軸上的修剪、剪切、變速與動態模糊。**
- **旁白與音樂。** 兩者都能加上旁白與背景音樂。Screen Studio 內建音樂庫。OpenScreen 則在時間軸上錄製旁白，並可匯入你自己的音訊檔案。
- **在你自己的電腦上轉錄。** 兩者都在本機執行 Whisper，將字幕顯示在影片上，並讓你修正逐字稿。詳見[字幕](/features/captions/)。
- **隱藏敏感內容。** Screen Studio 用遮罩模糊敏感資料。OpenScreen 則有高斯模糊或馬賽克模糊區域。
- **錄影時顯示筆記。** 兩者都有講者筆記功能。在 Windows 與 macOS 上，OpenScreen 的筆記視窗還有提詞機模式。
- **本機處理。** Screen Studio 表示它絕不會把你的錄影資料送到其伺服器。OpenScreen 沒有帳號、沒有自己的伺服器，也不會做任何分析追蹤。[常見問題](/docs/faq/#does-openscreen-work-offline)列出了它仍會連線的少數幾種情況。

## OpenScreen 的不同之處 {#where-openscreen-differs}

### 價格、授權與平台 {#price-license-and-platforms}

- **完全免費，毫無保留。** 沒有方案、不需要帳號、匯出功能不會被鎖住，也允許商業使用。
- **MIT 授權的原始碼。** 程式碼公開在 [GitHub](https://github.com/getopenscreen/openscreen) 上。Screen Studio 則是閉源的。
- **支援 Windows 與 Linux，不只是 macOS。** Screen Studio 的常見問題表示近期沒有推出 Windows 版的計畫。OpenScreen 提供 Windows 安裝程式與 Microsoft Store 上架版本、供 Apple Silicon 與 Intel Mac 使用的 `.dmg` 檔，以及供 Linux 使用的 AppImage、`.deb`、`.rpm` 與 `.pacman`，還有一份 Nix flake。詳見 [Windows](/screen-recorder-windows/)、[macOS](/screen-recorder-mac/) 與 [Linux](/screen-recorder-linux/) 頁面。

### 剪輯 {#editing}

- **同一個專案中的多個片段。** 可匯入錄影或現有影片（MP4、MOV、MKV 等格式），重新排序，並為每個片段設定入點、出點與裁切範圍。Screen Studio 可以從一段現有影片開始建立專案，其路線圖將合併多段錄影為一個專案列為規劃中的功能。詳見[媒體庫](/docs/media-library/)。
- **標註。** 六種動畫效果的文字、八個方向的箭頭、圖片，以及模糊區域。Screen Studio 的路線圖將「標註」（描述為點擊動作的視覺或文字說明）列為暫停中。詳見[剪輯與時間軸](/docs/editing-timeline/)。
- **攝影機背景。** 在正式版中，可以在不使用綠幕的情況下移除、模糊或替換攝影機背景。Screen Studio 將攝影機背景移除列為 beta 功能。

### 匯出與自動化 {#export-and-automation}

- **編碼格式選擇。** MP4 匯出可選 H.264 或 H.265。Screen Studio 的匯出指南沒有記載編碼格式設定。詳見[匯出](/docs/export/)。
- **命令列介面。** 指令碼、CI 與程式碼代理都能透過[命令列](/docs/cli/)操作 OpenScreen。Screen Studio 的指南沒有命令列相關內容。
- **可選用自己金鑰的聊天剪輯。** 可連接 Claude、OpenAI、Gemini、Mistral、OpenRouter、MiniMax，或任何相容 OpenAI 介面的服務，並用一般語言描述剪切、縮放、變速或標註。每項變更都會成為一般可復原的編輯。在你連接提供者之前，這項功能是關閉的，而且同一個提供者也用來將字幕翻譯成 15 種語言。詳見 [AI 剪輯](/docs/ai-editing/)。

## Screen Studio 更適合的情況 {#when-screen-studio-is-the-better-choice}

- **你以連結分享影片。** Screen Studio 會為長度在 30 分鐘以內的錄影產生託管連結，觀眾可以留下對應到特定時間點的留言。OpenScreen 則給你一個檔案，讓你自行上傳到想分享的地方。
- **你要錄製 iPhone 或 iPad。** Screen Studio 能透過 USB 錄製並加上裝置外框。OpenScreen 錄製的是 Windows、macOS 或 Linux 的畫面。
- **你需要逐字稿檔案。** Screen Studio 可以匯出逐字稿。OpenScreen 則是把字幕燒錄進影片。

## 開始使用 {#getting-started}

1. 從[下載頁面](/download/)下載 OpenScreen。在 Windows 上，建議使用 Microsoft Store。
2. 依照[安裝](/docs/installation/)步驟進行。在 macOS 上，請在第一次錄影前授予「螢幕錄製」與「輔助使用」權限。
3. 依照[快速入門](/docs/quick-start/)錄下第一段影片，然後執行**自動加強 → 自動縮放**。

也想比較其他工具嗎？請見 [OpenScreen 與 Cap 比較](/compare/openscreen-vs-cap/)、[OpenScreen 與 OBS Studio 比較](/compare/openscreen-vs-obs/)、[取代 Camtasia](/alternatives/camtasia/)與[取代 Loom](/alternatives/loom/)，或回到 [OpenScreen 首頁](/)。
