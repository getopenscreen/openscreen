# 隱私權政策

最後更新：2026 年 10 月 18 日。

OpenScreen 是免費、開放原始碼的螢幕錄影與影片剪輯軟體。你的錄影、專案與逐字稿都會留在你的電腦上：應用程式沒有帳號、沒有雲端儲存空間，也沒有上傳功能。本頁列出所有確實會離開你電腦的資料，包括來自桌面應用程式、本網站、MCP 伺服器與代理程式外掛的資料。

## 誰是負責人 {#who-is-responsible}

OpenScreen 由 Etienne Lescot 維護，他是本頁所述資料的資料控管者。聯絡方式：privacy@getopenscreen.com。

## 桌面應用程式 {#the-desktop-app}

### 每天一次的匿名計數 {#an-anonymous-daily-count}

應用程式每天最多一次告知 PostHog（位於其歐盟的伺服器），有一個安裝處於活躍狀態。這項計數包含：

- 應用程式版本、作業系統與處理器架構；
- 應用程式的安裝方式（安裝程式、Microsoft Store、AppImage、Flatpak 等）；
- 這是否為該安裝當週與當月的第一次計數。

除此之外不包含任何內容：沒有安裝識別碼（每次計數都使用新的隨機 ID），沒有姓名，沒有檔案名稱，也不含任何與你錄影有關的資訊。位置查詢已關閉，PostHog 專案也設定為捨棄 IP 位址。目的是了解有多少人在使用 OpenScreen、使用哪些系統，這屬於本專案的正當利益。

若要關閉，請在系統匣選單中取消勾選**傳送匿名使用計數**，或設定環境變數 `DO_NOT_TRACK=1`。開發版本與 CI 執行絕不會傳送這項計數。

### 應用程式建立的連線 {#connections-the-app-makes}

- **GitHub。** 會自行更新的版本每 24 小時檢查一次新版本，你手動要求時也會檢查。GitHub 會依照[其隱私權聲明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)接收這項請求，包括你的 IP 位址。
- **Hugging Face 與 GitHub，只有一次。** 第一次轉錄時會從 huggingface.co 下載 Whisper 語音模型，在有 GPU 的電腦上還會從 github.com 下載字詞對時模型。轉錄本身在你的電腦上執行。
- **Google Fonts，僅限 1.x 中加入的字體。** 在先前版本中加入的自訂字體仍會在啟動時載入。
- **你的 AI 提供者，僅在你連接時。** 聊天剪輯會送出你的訊息，以及代理程式讀取的專案資料，例如時間軸與逐字稿。字幕翻譯會送出字幕文字。在你選擇提供者並提供你自己的 API 金鑰之前，不會送出任何資料。提供者（Anthropic、OpenAI、Google、Mistral、OpenRouter、MiniMax 或你設定的伺服器）會依照其自身條款處理這些資料。金鑰會加密儲存在你的電腦上。

應用程式不含任何當機回報功能。**儲存診斷資訊**會將檔案寫入你的磁碟，不會傳送任何資料。

## MCP 伺服器與代理程式外掛 {#the-mcp-server-and-the-agent-plugin}

OpenScreen 的 MCP 伺服器在你的電腦上執行：`openscreen mcp` 與啟動它的代理程式溝通，而內建於應用程式中的伺服器只在 127.0.0.1 上監聽，並受權杖保護。兩者都不會將任何資料傳出你的電腦。你所連接的代理程式（例如 Claude Code 或 Codex）會從它們接收專案資料與靜態畫面，並可能依照該代理程式的條款，將其傳給它自己的模型提供者。

`openscreen-demo` 技能與適用於程式設計代理程式的 OpenScreen 外掛，只會在你要求時傳送資料：

- 當你要求製作 pull request 影片時，它會使用 `gh` 將匯出的影片附加到 GitHub pull request；
- 它只會在你明確同意後才在 X 上發布影片；
- 如果你同意安裝應用程式，它會從 GitHub releases 下載 OpenScreen 安裝程式。

## 本網站 {#this-website}

getopenscreen.com 由 Cloudflare 提供服務，Cloudflare 會依照[其隱私權政策](https://www.cloudflare.com/privacypolicy/)處理其所服務的請求，包括你的 IP 位址。

本網站使用 PostHog（位於其歐盟的伺服器）衡量訪客數，不使用 Cookie，也不會在你的瀏覽器中儲存任何資料。它會記錄你瀏覽的頁面、你點擊的連結與按鈕，以及你下載的檔案。訪客是以 PostHog 在其伺服器上計算的每日雜湊值計數，無法從一天連結到下一天。不會建立個人檔案，也不會錄製工作階段。目的是了解哪些頁面能幫助大家找到並下載 OpenScreen，這屬於本專案的正當利益。

示範影片由 media.getopenscreen.com 提供。效能測試文章會從由 GitHub 提供服務的 etiennelescot.github.io 載入其結果。

## 資料保留期限 {#how-long-data-is-kept}

應用程式的每日計數與網站的訪客事件在 PostHog 中最多保留一年。OpenScreen 不保留其他任何個人資料。

## 你的權利 {#your-rights}

依據 GDPR，你可以要求存取、更正或刪除與你有關的資料，反對其處理，或限制其處理。由於計數不帶任何識別碼，通常無法追溯到你本人。請寫信至 privacy@getopenscreen.com。你也可以向你所在地的資料保護主管機關提出申訴；在法國，該機關是 [CNIL](https://www.cnil.fr/)。

## 變更 {#changes}

當 OpenScreen 開始或停止傳送某項資料時，本頁就會變更。頂端的日期顯示最後一次變更，而[本頁的歷史紀錄](https://github.com/getopenscreen/openscreen/commits/main/website/src/pages/privacy.mdx)會顯示每一次編輯。
