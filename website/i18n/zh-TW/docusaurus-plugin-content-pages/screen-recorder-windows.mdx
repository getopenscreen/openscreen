# 免費、開源的 Windows 螢幕錄影軟體

OpenScreen 是免費、MIT 授權、支援 Windows 10 與 11 的螢幕錄影軟體，同時也能把錄下的內容剪輯成完整的影片。在 Windows 上，它透過 Windows Graphics Capture 錄製，不需要額外驅動程式就能收錄系統音訊，寫出的檔案即使錄影軟體當機也能繼續播放，並匯出不含浮水印的 MP4 或 GIF，全程不需要帳號。如果你需要直播，OBS Studio 仍然是較好的選擇。

本頁由 OpenScreen 專案發布。其他工具的資訊來自各自的官方網站與說明文件，於 2026 年 9 月確認。資料來源列於文末。

## OpenScreen 在 Windows 上的功能 {#what-openscreen-does-on-windows}

奠定這類錄影軟體樣貌的 Screen Studio 僅支援 macOS，其常見問題表示近期沒有推出 Windows 版的計畫（截至 2026 年 9 月）。OpenScreen 在 Windows 上運作，並透過系統本身的擷取、音訊與編碼 API 進行錄製。如果你是因為 Screen Studio 而來到這裡，[Screen Studio 替代方案](/alternatives/screen-studio/)頁面比較了這兩款軟體。

### 錄製 {#recording}

- **原生擷取。** 一個以 Windows Graphics Capture 為基礎的輔助程式，從 Windows 10 組建 19041 開始，可錄製螢幕畫面或單一視窗。目標為 60 fps，最高 3840×2160。之後可在編輯器中裁切畫面。詳見[錄影](/docs/recording/)。
- **有硬體支援時使用硬體 H.264。** 該輔助程式透過 Media Foundation 進行編碼。自 1.11 版起，只要已安裝可正常運作的硬體編碼器，就會使用它。
- **能撐過當機的錄影檔。** 錄影會以每秒一段的方式寫成 Fragmented MP4。如果擷取處理程序中斷，檔案仍可播放到最後一個完整片段為止。如果該處理程序未能正常結束而直接退出，OpenScreen 仍會保留可播放的檔案，並像處理其他錄影一樣開啟它。
- **不需要驅動程式的系統音訊。** WASAPI loopback 會擷取電腦播放的聲音，不需要安裝虛擬音訊裝置，並與麥克風混音在同一軌道上。
- **透過 Media Foundation 使用攝影機。** Media Foundation 無法辨識的攝影機，例如 NVIDIA Broadcast，會透過 DirectShow 備援方案擷取。攝影機會另存為獨立檔案，並在編輯器中合成。
- **不會出現在畫面中的控制項。** 在 Windows 10 組建 19041 及更新版本上，浮動的錄製控制項與筆記視窗不會出現在擷取畫面中，所以錄影時仍可將它們留在畫面上。筆記視窗提供提詞機模式。
- **可在事後更改的游標。** 在預設模式下，實際的游標形狀與點擊會以資料而非像素的形式錄下。你可以在錄完後調整游標大小、使其平滑並重新設計樣式，而自動縮放也是根據這份移動資料來放置的。

### 剪輯與匯出 {#editing-and-export}

- **與 macOS、Linux 相同的編輯器。** 多片段時間軸、修剪、變速、標註、背景、攝影機版面，以及根據錄下的游標放置的**自動加強 → 自動縮放**。詳見[自動縮放](/features/auto-zoom/)與[剪輯與時間軸](/docs/editing-timeline/)。
- **以 Direct3D 11 算繪。** 即時預覽與 MP4 匯出共用同一個原生合成器，在 Windows 上以 Direct3D 11 執行。
- **硬體匯出編碼器。** MP4 匯出會依序嘗試 AMD AMF、NVIDIA NVENC、Intel Quick Sync 與 Media Foundation，最後才使用軟體編碼器。可選擇 H.264 或 H.265、720p、1080p 或 Source 品質，以及 24、30 或 60 fps。GIF 匯出也可使用，兩種格式都不含浮水印。詳見[匯出](/docs/export/)。想了解匯出速度，請閱讀[匯出效能評測（英文）](/blog/2026/09/09/an-export-benchmark-hard-to-fake/)文章及其註明事項。
- **沒有可用 GPU 時的匯出。** 在沒有相容 GPU 的電腦上，OpenScreen 會透過 WARP 在 CPU 上算繪，並使用軟體解碼。匯出對話框會在開始前先告知這一點，而且匯出所需時間會較長。
- **在你的電腦上產生字幕。** whisper.cpp 在 Vulkan 上執行，並提供 CPU 備援方案。它使用一個約 264 MB 的 Whisper Small 模型，下載一次即可，字幕會燒錄進影片。詳見[字幕](/features/captions/)。
- **命令列介面。** [CLI](/docs/cli/) 可錄製、匯出、加字幕並打包專案，並支援 JSON 輸出。若使用安裝程式安裝，可從安裝時選擇的資料夾中執行 `Openscreen.exe`。

### 安裝與更新 {#installing-and-updating}

- **建議使用 Microsoft Store。** Microsoft 會在認證過程中為套件簽署，因此安裝時不會出現警告，Store 也會自動保持更新。從終端機執行：`winget install --source msstore OpenScreen`。
- **獨立的 `.exe` 安裝程式。** 適用於無法使用 Store 的情況。檔案大小約 231 MB，未經過程式碼簽署，因此 SmartScreen 會顯示「Windows 已保護您的電腦」。請選擇**其他資訊**，再選擇**仍要執行**。
- **`.exe` 版本的更新。** 應用程式每 24 小時檢查一次新版本，預設只會通知你。你可以設定為自動下載更新，或自動下載並安裝。安裝一律會經過重新啟動的提示，而且錄影期間絕不會提示更新。
- **會連線的內容。** OpenScreen 沒有帳號、沒有自己的伺服器，也不會做任何分析追蹤。但仍會在幾種情況下連線：啟動時載入字型、一次性的 Whisper 模型下載、更新檢查，以及在你自行連接 AI 提供者時。

## 不適合使用 OpenScreen 的情況 {#when-openscreen-is-not-the-right-tool}

- **你的電腦執行 Windows on ARM。** OpenScreen 僅提供 x64 版本。OBS Studio 提供 Windows ARM64 壓縮檔（截至 2026 年 9 月）。
- **你的 Windows 10 版本早於 2004。** OpenScreen 支援 Windows 10 1903 版起，但原生錄影功能需要組建 19041。更早的版本只能透過瀏覽器擷取備援方案錄製，無法使用上述原生擷取功能。
- **你要直播。** OpenScreen 只負責錄製與剪輯，不支援直播。同樣免費開源的 OBS Studio 則可以錄製並即時直播。
- **你要以連結分享錄影。** OpenScreen 給你一個檔案，讓你自行上傳到想分享的地方。Cap 可以把錄影發布成觀眾能在瀏覽器中觀看的網頁，Loom 則透過附存取權設定的複製連結來分享錄影。詳見 [OpenScreen 與 Cap 比較](/compare/openscreen-vs-cap/)與[取代 Loom](/alternatives/loom/)。

## 開始使用 {#getting-started}

1. 從 Microsoft Store 安裝 OpenScreen，或從[下載頁面](/download/)取得 `.exe`。
2. 依照[安裝](/docs/installation/#windows)頁面中 Windows 的步驟進行，並在同一頁確認系統需求。
3. 依照[快速入門](/docs/quick-start/)錄下第一段影片，然後執行**自動加強 → 自動縮放**。

使用其他系統嗎？請見 OpenScreen 的 [macOS](/screen-recorder-mac/) 與 [Linux](/screen-recorder-linux/) 版本。想比較工具嗎？請見[取代 Screen Studio](/alternatives/screen-studio/)、[OpenScreen 與 OBS Studio 比較](/compare/openscreen-vs-obs/)與[取代 Camtasia](/alternatives/camtasia/)。[常見問題](/docs/faq/)回答了安裝前大家常問的問題，或回到 [OpenScreen 首頁](/)。
