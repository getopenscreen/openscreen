# 使用條款

最後更新：2026 年 11 月 3 日。

如 MIT 授權所述，本軟體依「現狀」提供，不附帶任何形式的擔保。請為重要的錄影與專案保留副本。在法律允許的範圍內，維護者不對因使用本軟體造成的任何損失負責。

部分功能仰賴你自行選擇使用的服務，例如以你自己的 API 金鑰連接的 AI 服務商，或用於更新的 GitHub。這些服務適用其各自的條款。哪些資料會離開你的電腦，詳見[隱私權政策](/privacy/)。
